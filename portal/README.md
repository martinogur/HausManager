Zentrales Portal für Kunden, Objekte, Aufträge, Einsatzplanung, Zeiterfassung, Bewerbungen, Angebote, Rechnungen und E-Mails.

**Stand:** Phase 1 (Architektur & Datenmodell) – wartet auf Freigabe.

- Architektur, Entscheidungen, Kosten, Plan: [`docs/01-architektur.md`](docs/01-architektur.md)
- Datenmodell: [`docs/02-datenmodell.md`](docs/02-datenmodell.md), [`db/schema.sql`](db/schema.sql)
- Tests Datenmodell: `bash portal/db/tests/run.sh` (PostgreSQL 16)

Regeln: keine Zugangsdaten im Code oder Chat · externe E-Mails nur nach Freigabe · keine kostenpflichtigen Dienste und keine Echtdaten ohne Freigabe.
